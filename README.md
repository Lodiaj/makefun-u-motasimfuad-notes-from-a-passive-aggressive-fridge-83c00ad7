One funny passive-aggressive note a smart fridge leaves for its owner, written
by a small program. `main.ts` writes a single line to `/output/entry.txt`.

The note:

> You opened the door six times looking for a snack, found nothing, and blamed me. I did not hide the snacks. I ate them.

## Run

```sh
node main.ts
```

It writes the note to `/output/entry.txt` (1–200 characters, a single line).
